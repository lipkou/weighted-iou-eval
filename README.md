# weighted-iou-eval

Оценка качества разметки (детекция и сегментация): предсказанная разметка сравнивается с эталонной.
Результат — оценка каждого объекта, каждого класса и всего файла в процентах, плюс precision/recall и совпадение атрибутов.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt     # Linux/macOS: .venv/bin/python

.venv/Scripts/python -m weighted_iou road_data/ground_truth/road.jpg.json road_data/annotated/road.jpg.json
.venv/Scripts/python -m weighted_iou GT.json PRED.json --config config.toml --json
.venv/Scripts/python -m pytest
```

## Метрика

Обозначения: g — объект эталона, p — объект предсказания, A — площадь в пикселях, w(A) — вес объекта (`A` или `√A`, `scoring.object_weight`).

1. **Сопоставление** — без учёта класса, венгерский алгоритм по максимуму суммарного IoU. Пара с IoU < `matching.min_iou` не засчитывается.
2. **Объект:** `s_g = IoU(g, p)`, если g сопоставлен с p и классы совпали, иначе 0.
   Неверный класс — это пропуск в классе эталона и FP в классе предсказания; в отчёте помечается «нашёл, но не тот класс».
3. **Класс c** (классы эталона и предсказания вместе):

   ```
   S_c = Σ w(A_g)·s_g / ( Σ w(A_g) + λ·Σ_{p∈FP_c} w(A_p) )
   ```

   λ = `scoring.fp_penalty`; при λ = 1 ложный объект стоит столько же, сколько пропуск объекта той же площади.
   Класс, где есть только FP, получает 0.
4. **Файл:** `S = Σ W_c·S_c / Σ W_c`, W_c — вес класса из `config.toml`. Пустой кадр с обеих сторон = 100%.
5. **Precision / recall** по классу: TP — совпавший класс и IoU ≥ `tp_iou` класса (по умолчанию `scoring.default_tp_iou`). Порог влияет только на счётные метрики, не на оценку.
6. **Атрибуты** в оценку не входят: выводится доля совпавших значений объектов и расхождения атрибутов кадра (например, погоды).

## Формат данных

JSON — список из двух блоков: `[0]` — метаданные кадра и типы объектов, `[1]` — геометрия; связь по `nm`.
Номера `nm` в эталоне и предсказании независимы. Геометрия берётся из маски `<file>.images/<frame>/<nm>.png`, если она есть, иначе из полигона `path`, иначе из bbox.
Имена классов нормализуются: `road sign` = `road_sign`.
